  <TabItem value="phone" label="MacOS">
		1. Run the command provided to you in the terminal. It should ask for your password, and near it's completion, it should say please allow a few minutes for the agent to show up in the dashboard.
		2. Open Finder and go to the /opt/meshagent folder
		3. Right click on "meshagent" and select Make Alias
		4. Move that alias file to the Applications folder
		5. Open Finder and go to the /opt/tacticalagent folder
		6. Right click on "tacticalagent" and select Make Alias
		7. Move that alias file to the Applications folder
		8. Open System Settings/Preferences and head to the Security and Privacy section
		9. Grant Accessibilty, Screen Recording/Screen & System Audio Recording, and Full Disk Access permissions to both the meshagent and tacticalagaent we put into the Applications folder
