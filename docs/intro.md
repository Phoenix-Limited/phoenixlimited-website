# Welcome to the wiki!

Here you can find all kinds of guides or other informational tidbits about how to use Phoenix Limited services

### What you can expect to find here

You'll see things like how to sign in to some specific services, how to install agents for the RMM service, and control schemes for some of the games offered, just to name a few things.

### How to navigate this site:

On the top, you'll see the **Navigation Bar** where you can get to the top-level information sets such as general documentation and games documentation.

On the left is the **sidebar**, which also has categories breaking down all the documentation on the different services that are provided.
